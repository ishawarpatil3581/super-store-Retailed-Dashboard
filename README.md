# 📊 Superstore Sales Analysis Dashboard | Excel

An interactive **Superstore Sales Analysis Dashboard** built in Microsoft Excel using **Power Query, Power Pivot, DAX, Pivot Tables, Pivot Charts, Slicers, and Filters**.

The project transforms raw Superstore data into a structured data model and interactive dashboard to analyze **sales, profit, profit margin, products, customers, regions, segments, shipping modes, and returns**.

---

## 📌 Project Overview

This project demonstrates an end-to-end **Data Analytics and Business Intelligence workflow using Microsoft Excel**.

The raw Superstore dataset is cleaned and transformed using **Power Query**. The transformed data is then organized into a structured **Power Pivot data model** using fact and dimension tables.

DAX measures are created to calculate important KPIs, which are visualized using Pivot Tables, Pivot Charts, Slicers, and Filters.

## 🎯 Project Objectives

- Clean and transform raw Superstore data using **Power Query**.
- Build a structured **data model using Power Pivot**.
- Create relationships between fact and dimension tables.
- Develop reusable **DAX measures**.
- Analyze sales and profitability across different business dimensions.
- Create interactive Pivot Charts and KPI visualizations.
- Use Slicers and Filters for dynamic analysis.
- Identify important business trends and performance patterns.
- Build a professional and interactive Excel dashboard.

## ❓ Business Questions

### Sales & Profitability

- What is the total sales generated?
- What is the total profit?
- What is the overall profit margin?
- How does sales performance change over time?
- Which categories generate the most sales?

### Product Analysis

- Which product categories perform best?
- Which sub-categories contribute the most to sales?
- Which products generate higher or lower profitability?

### Regional Analysis

- Which region generates the highest sales?
- Which region contributes the most profit?
- How does performance vary across regions?
- How does regional manager performance compare?

### Customer Analysis

- Which customer segments contribute most to sales?
- How does performance differ between Consumer, Corporate, and Home Office segments?

### Shipping & Returns

- Which shipping modes are most frequently used?
- How does shipping mode affect business performance?
- Which orders have been returned?
